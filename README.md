Unisson (YC W26) builds AI agents that act as subject-matter experts for B2B software implementation and customer-facing teams. Its Runner agent executes complex deployment, onboarding, and administration tasks directly inside a product, while Explorer maintains an always up-to-date knowledge base of how the product works. Agents are reachable over Slack, Microsoft Teams, WhatsApp, email, and an embeddable widget, and the platform exposes a bearer-token REST API (api.unisson.ai) covering agents, runs, scheduled runs, skills, knowledge base, integrations, customers, meetings, and an external Runner API for triggering runs and receiving webhook callbacks from your own tools.

**Areas:** Company · Artificial Intelligence · AI Agents · Customer Success · B2B Software · Implementation · Automation · Agents

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Unisson: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
