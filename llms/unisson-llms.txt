# Unisson

> Unisson (YC W26) builds AI agents that act as subject-matter experts for B2B software implementation and customer-facing teams. Runner executes deployment, onboarding, and administration tasks inside a product; Explorer maintains a live knowledge base of how the product works. A bearer-token REST API at api.unisson.ai exposes agents, runs, skills, knowledge base, integrations, and an external Runner API for third-party tools.

Generated by API Evangelist from the harvested OpenAPI and site survey on 2026-07-21 (no provider-published llms.txt found at unisson.ai/llms.txt or api.unisson.ai/llms.txt).

## Notes for agents

- Authentication: HTTP bearer token (Authorization: Bearer ...). Organization API keys are managed at /api/v1/organizations/me/api-keys.
- Versioning: URI path, current v1 (/api/v1/...).
- Errors: FastAPI-style 422 validation errors (HTTPValidationError with detail[].loc/msg/type); not RFC 9457 problem+json.
- External integration surface: POST /api/v1/external/runs to trigger a run, GET /api/v1/external/runs/{run_id} to poll, PUT /api/v1/external/webhook to register a callback for run events.
